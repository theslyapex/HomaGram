# HomaGram | هماگرام

**ارتباطی فراتر از مرزها**  
*Connection Beyond Boundaries*

HomaGram یک محصول مستقل شبکه اجتماعی و پیام‌رسان چندمنظوره است که با الهام از قابلیت‌های محبوب شبکه‌های اجتماعی و پیام‌رسان‌ها، هویت بصری و فنی اختصاصی خود را خواهد داشت.

## وضعیت پروژه

- مرحله فعلی: **مرحله صفر — آماده‌سازی پروژه**
- پلتفرم آغازین: Android
- اپلیکیشن: Flutter / Dart
- بک‌اند: پروژه مستقل Supabase
- مخزن: خصوصی و مستقل از پروژه‌های دیگر

در این Commit فقط اسکلت اولیه، صفحه راه‌اندازی، مستندات معماری و گردش‌کار CI ایجاد شده‌اند. هنوز قابلیت محصولی مانند ثبت‌نام، ارسال پیام یا انتشار محتوا پیاده‌سازی نشده است.

## اجرای محلی

1. Flutter و Android toolchain را نصب کنید.
2. وابستگی‌ها را دریافت کنید:

   ```bash
   flutter pub get
   ```

3. اپ را بدون اتصال بک‌اند اجرا کنید:

   ```bash
   flutter run
   ```

4. برای مقداردهی Supabase، مقادیر پروژه مستقل HomaGram را فقط در محیط توسعه خود وارد کنید:

   ```bash
   flutter run \
     --dart-define=SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co \
     --dart-define=SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
   ```

کلید Publishable/Anon برای استفاده در کلاینت طراحی شده است؛ هرگز کلید Secret یا service_role را در اپلیکیشن، فایل‌های مخزن یا GitHub Actions قرار ندهید.

## ساختار

- `lib/app`: راه‌اندازی و پوسته اصلی اپ
- `lib/features`: قابلیت‌ها به‌صورت ماژولار
- `test`: تست‌های اپلیکیشن
- `docs`: معماری، امنیت و نقشه راه
- `supabase/migrations`: محل نگهداری تغییرات نسخه‌بندی‌شده دیتابیس
- `.github/workflows`: بررسی خودکار کد و Build آزمایشی Android
