# نقشه راه رسمی توسعه

| مرحله | محدوده | خروجی مورد انتظار |
|---|---|---|
| صفر | هویت، مخزن، محیط Flutter، معماری، CI | زیرساخت آماده توسعه |
| یک | شروع، ثبت‌نام، ورود، بازیابی رمز، پروفایل، نشست و ناوبری | هسته قابل ورود |
| دو | خانه، پست، گالری، پسندیدن، نظر، دنبال‌کردن و جست‌وجو | شبکه اجتماعی اولیه |
| سه | استوری، آرشیو، هایلایت و ریلز | محتوای تصویری و ویدئویی |
| چهار | پیام خصوصی، متن، رسانه، فایل، صوت و وضعیت پیام | پیام‌رسان خصوصی |
| پنج | گروه‌ها، نقش‌ها، مجوزها و کانال‌ها | ارتباط گروهی |
| شش | اعلان‌ها، حریم خصوصی، گزارش، مسدودسازی و امنیت | نسخه آماده آزمون عمومی |
| هفت | تماس صوتی، تصویری و گروهی | ارتباط زنده |
| هشت | پنل مدیریت و گزارش‌ها | زیرساخت نظارت |
| نه | تست، امنیت، عملکرد و بازیابی | نسخه پایدار |
| ده | امضا، APK/AAB، فروشگاه‌ها و پایش | انتشار عمومی |
